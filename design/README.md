# ColiUI designs

A copy of the design canvas the app is built from: https://claude.ai/artifact/3MwzFhm1Mg27A5BSHcpZoR (private to its owner).

The canvas is the source of truth: new screens are designed and approved there first, then built to match it exactly. This folder is a read-only snapshot for reference and history; edit the canvas, then refresh the copy.

- `canvas.json` — the layout: each artboard's title, position and size, and the row titles.
- `<Name>.dc.html` — one artboard each (Main, Detail, Settings, Updates, …). Each is plain HTML and CSS plus a small `Component` script for its sample data and interactions.

The files load `support.js` from the canvas editor, which isn't part of this copy, so opening one in a browser shows the static markup without its sample data or interactions. To see them rendered, open the canvas link.

Snapshot taken 2026-11-03 (27 artboards).
